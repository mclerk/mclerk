# Hey, I'm Michael 👋

> *Building software - and guiding the decision makers - that keep real businesses running.*

I build enterprise software for the businesses that actually keep economies moving — the SMEs, the owner/operators who need tools that just work for them, not the other way round.

I'm also a consultant, drawing on years of experience running my own businesses and following the technology landscape closely — advising others on how to run their operations and build better software.

## Why Enterprise?

I grew up watching SAP run my family's business and thought: *I can build something better.*

I've run my own businesses my entire professional life. I've lived inside Windows, QuickBooks, spreadsheets, and duct-taped workflows — as the person who had to make it work every day — I know the pain of bad software.

That's the lens I bring to everything. I'm not solving hypothetical enterprise problems. I'm solving the ones I've already lived.
